# Prior art

The split this tool builds on — a full-context author drafts the design, isolated
reviewers with no conversation read it — was popularised by Google's
Elephant-Goldfish Model (Apache-2.0, https://github.com/google/elephant-goldfish-model).

No text, prompt or code from that project is used here. The personas, the prompt
template, the artifact schema and both gates in this repository are original.

The reviewer-isolation idea is not patentable and not the interesting part; the part
worth building on is that a review which cannot be re-checked is not evidence.
